# 🤖 AI News Bot — کانال تلگرام اخبار هوش مصنوعی

یک ربات تلگرام که به‌صورت خودکار اخبار مدل‌های هوش مصنوعی را از سطح اینترنت جمع‌آوری، به فارسی خلاصه و در کانال شما منتشر می‌کند.

## ویژگی‌ها

- 📰 **جمع‌آوری خودکار** از +19 منبع
- 🇮🇷 **ترجمهٔ همهٔ اخبار** به فارسی با زنجیرهٔ مترجم‌های رایگان (Google → MyMemory → Lingva)؛ **Gemini هیچ نقشی در ترجمه ندارد**
- 🌐 **متن اصلی زیر ترجمه**: هر خبر انگلیسی با ترجمهٔ فارسی منتشر می‌شود و متن اصلی در یک بلوک جمع‌شونده زیرش می‌آید
- 🔤 **برچسب «ترجمه نشده»** اگر همهٔ مترجم‌ها شکست بخورند (خبر با متن اصلی منتشر می‌شود، کانال نمی‌خوابد)
- 📈 **اعتبار پویای منابع**: اعتبار هر منبع با تایید/رد شما و تایید چندمنبعی خودکار به‌روز می‌شود
- 🔁 **ضدتکرار** — هر خبر فقط یک‌بار در کانال منتشر می‌شود
- 🧠 **طبقه‌بندی محلی** (بدون LLM): دسته + مهم/متوسط/کم + قطعی/احتمالی/شایعه
- ✅ **تایید شما**: اخبار مهم و غیرقطعی قبل از انتشار بررسی می‌شوند
- 🗑 **پاک‌کردن کل صف** با یک دکمه (با تایید دوباره)
- ⭐️ **ویژه** · ✏️ **ویرایش** · 🤖 **انتشار خودکار** برای منابعی که اعتبار پویایشان کافی است
- 💰 **کاملاً رایگان**

## منطق انتشار

```
 خبر جدید → Auto-Reject (کلمات مشکوک)
          → طبقه‌بندی محلی + اعتبار پویای منبع + تایید چندمنبعی
          → امتیاز < ۳۰؟ رد
          → ترجمه (فقط خبرهای باقی‌مانده)
          ├─ اعتبار ≥ ۴ و «قطعی» و امتیاز ≥ ۷۰ → ✅ انتشار خودکار
          └─ غیر این صورت                       → 👀 دکمه‌های تایید برای شما
```

### اعتبار پویای منابع

`TRUST_SCORES` در `src/config.py` فقط **پیش‌فرض اولیه** است. اعتبار واقعی هر منبع (۱ تا ۵) از این‌ها ساخته می‌شود:

| سیگنال | اثر |
|---|---|
| ✅ تایید شما | به نفع منبع (+۱) |
| ⭐️ ویژه | به نفع منبع (+۱٫۵) |
| ❌ رد شما | به ضرر منبع (−۱) |
| 🗑 پاک‌کردن صف | **خنثی** — در اعتبار حساب نمی‌شود |
| 🔗 همان خبر در منبع‌های مستقل دیگر | +۰٫۵ به اعتبار *همان خبر* به‌ازای هر منبع (حداکثر +۱) و با ۲ منبع، خبر «قطعی» می‌شود |
| ⏳ گذشت زمان | تصمیم‌های قدیمی با نیمه‌عمر ۳۰ روز کم‌اثر می‌شوند |

فرمول: `trust = 1 + 4 × (pos + prior_rate×K) / (pos + neg + K)` با `K = TRUST_PRIOR_WEIGHT` (پیش‌فرض ۸).
نتیجه: منبعی که پشت‌سرهم تایید می‌شود به‌تدریج به انتشار خودکار می‌رسد، و منبع معتبری که مدام رد می‌شود خودکار به «نیازمند تایید» برمی‌گردد.
با دستور `/sources` وضعیت لحظه‌ای همهٔ منابع را ببین.

### فیلتر «خبر دربارهٔ AI»

- **فیدهای اختصاصی AI** (`trusted=True`، مثل OpenAI/MIT AI/TechCrunch AI) اصلاً فیلتر نمی‌شوند؛ لازم نیست «AI» توی متن بیاید.
- **فیدهای عمومی** (TechCrunch، The Verge، دیجیاتو، …) با **امتیاز** فیلتر می‌شوند، نه با یک کلیدواژه:
  هر واژه در عنوان/تگ‌های RSS دو برابر و در خلاصه یک برابر حساب می‌شود و امتیاز ≥ ۳ یعنی مرتبط.
  نام شرکت/مدل/فرد (OpenAI، Gemini، Nvidia، Sam Altman، گراک، …) به‌تنهایی کافی است؛
  واژهٔ ضعیف (robot، algorithm، …) فقط در کنار نشانهٔ دیگر.
- **تگ‌های خود RSS** (مثلاً دستهٔ «Artificial Intelligence») هم امتیاز می‌دهند.
- واژه‌ها و وزن‌ها در `src/ai_terms.py` هستند؛ بدون دست‌زدن به کد ویرایش کن.
- `/feeds` برای هر فید نمونه‌ای از خبرهای ردشده با فیلتر را نشان می‌دهد (🚫) تا بفهمی فیلتر چه چیزی را می‌اندازد.
- سقف ۳۰ خبر در هر اجرا حالا **نوبتی بین منابع** اعمال می‌شود (قبلاً منابع آخر لیست، یعنی فارسی‌ها، حذف می‌شدند).
- لیست رد خودکار (crypto، casino، …) با مرز کلمه کار می‌کند؛ «cryptography» دیگر رد نمی‌شود.

### ترجمه

`src/translator.py` متن را تکه‌تکه (مرز جمله) ترجمه می‌کند. خطای هر مترجم جداگانه شمرده می‌شود و بعد از ۳ خطای پشت‌سرهم همان مترجم تا پایان اجرا کنار می‌رود، بقیه ادامه می‌دهند.
برای خاموش‌کردن بلوک متن اصلی: `SHOW_ORIGINAL_TEXT=false`.

### محافظ‌های اجرای پایدار

| تنظیم                  | پیش‌فرض   | کار                                        |
|------------------------|-----------|--------------------------------------------|
| `MAX_ARTICLES_PER_RUN` | 30        | سقف پردازش هر اجرا (جلوگیری از تایم‌اوت)   |
| `MAX_REVIEWS_PER_RUN`  | 5         | سقف پیام «در انتظار تایید» برای ادمین      |
| `MAX_POSTS_PER_RUN`    | 15        | سقف انتشار در **هر راند اجرا** (نه روزانه) |
| `MAX_POSTS_PER_DAY`    | 0 (خاموش) | سقف امنیتی اختیاری روزانه                  |
| `COLLECT_INTERVAL_MIN` | 45        | حداقل فاصله بین دو جمع‌آوری                |
| `SHOW_ORIGINAL_TEXT`   | true      | متن اصلی زیر ترجمه                          |
| `MAX_PER_FEED`         | 15        | از هر فید جدیدترین N آیتم (بر اساس تاریخ)    |
| `MAX_ITEM_AGE_HOURS`   | 72        | خبر قدیمی‌تر از این نادیده گرفته می‌شود       |
| `TRUST_PRIOR_WEIGHT`   | 8         | وزن اعتبار اولیه (بزرگ‌تر = دیرتر تغییر)     |
| `TRUST_HALF_LIFE_DAYS` | 30        | نیمه‌عمر تصمیم‌های قدیمی                    |

## معماری

```
GitHub Actions (هر ۱ ساعت)
  ├── Auto-Reject ← فیلتر کلمات مشکوک
  ├── Collect    ← RSS ۱۹ منبع
  ├── Analyze    ← طبقه‌بندی محلی + اعتبار پویا
  ├── Translate  ← Google → MyMemory → Lingva
  └── Publish    ← اخبار تایید/خودکار

Cloudflare Worker (۲۴/۷ همیشه فعال)
  ├── Webhook ← دستورات و دکمه‌های ادمین (تایید/رد/ویژه/پاک‌کردن صف)
  ├── Publish ← تایید فوری ادمین (بلافاصله در کانال)
  └── KV      ← وضعیت مشترک با Actions (از جمله source_stats)
```

## راه‌اندازی (۵ قدم)

### 1. ساخت ربات تلگرام
1. به [@BotFather](https://t.me/BotFather) پیام بدهید
2. `/newbot` → نام و یوزرنیم انتخاب کنید
3. **توکن** را کپی کنید

### 2. ساخت کانال تلگرام
1. کانال بسازید
2. ربات را به‌عنوان **ادمین** اضافه کنید (دسترسی ارسال پیام)
3. آیدی عددی کانال را پیدا کنید (از [@userinfobot](https://t.me/userinfobot))
4. آیدی عددی خودتان را هم از همان ربات بگیرید

### 3. (لازم نیست) Gemini

Gemini فعلاً در پروژه استفاده نمی‌شود و کلید API نمی‌خواهد.

### 4. ساخت مخزن GitHub
1. یک **مخزن عمومی (Public)** بسازید (برای رایگان ماندن Actions)
2. پوشه `data/` و `.github/` را بسازید
3. همه فایل‌های پروژه را آپلود کنید

### 5. ساخت Cloudflare KV

1. وارد [Cloudflare Dashboard](https://dash.cloudflare.com) شوید → **Workers & Pages** → **KV**
2. **Create namespace** → نام: `ai-news-bot`
3. دو مقدار لازم دارید:
   - **Account ID** (از صفحه اصلی Workers)
   - **Namespace ID** (از صفحهٔ همان KV)

### 6. تنظیم Secrets در GitHub

مخزن → **Settings** → **Secrets and variables** → **Actions** → این‌ها را اضافه کنید:

| Secret | مقدار |
|--------|-------|
| `TELEGRAM_BOT_TOKEN` | توکن ربات |
| `TELEGRAM_CHANNEL_ID` | `@ai_news_bot_telegram` یا آیدی عددی |
| `TELEGRAM_ADMIN_ID` | آیدی عددی ادمین |
| `CF_ACCOUNT_ID` | Account ID کلادفلر |
| `CF_KV_NAMESPACE` | Namespace ID |
| `CF_API_TOKEN` | توکن API با دسترسی **Workers KV Storage → Edit** |

### 7. تنظیم Worker در Cloudflare

1. **Workers & Pages** → **Create** → **Worker** → نام: `ai-news-bot-worker`
2. کد `worker/index.js` را در **Edit code** جای‌گذاری کنید → **Save and Deploy**
3. **Settings → Variables and Secrets** → این‌ها را به‌صورت **Secret** اضافه کنید:
   - `BOT_TOKEN` — توکن ربات
   - `CHANNEL_ID` — آیدی کانال
   - `ADMIN_ID` — آیدی عددی ادمین
   - `WORKER_SECRET` — یک رشتهٔ تصادفی (برای محافظت از `/run`)
4. **Settings → Bindings** → **KV Namespace** → نام متغیر: `KV` (باید دقیقاً `KV` باشد) → همان namespace
5. آدرس Worker را کپی کنید (مثلاً `https://ai-news-bot-worker.xxx.workers.dev`)

### 8. اتصال Webhook

یک‌بار این آدرس را در مرورگر باز کنید:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<WORKER_URL>/webhook
```

باید `{"ok":true,...}` ببینید. سپس در ربات `/start` بزنید.

> اگر `WEBHOOK_SECRET` را در Worker تنظیم کردید، باید `&secret_token=<همان مقدار>` را هم به آدرس بالا اضافه کنید.

### 9. (اختیاری) اجرای مطمئن هر ساعت

GitHub گاهی اجرای زمان‌بندی‌شده را ۴-۵ ساعت عقب می‌اندازد. برای اجرای قطعی هر ساعت:

1. یک **GitHub Fine-grained Token** بسازید با دسترسی **Actions: Read and write** روی همین مخزن.
2. در Worker دو Secret اضافه کنید:
   - `GITHUB_TOKEN` — همان توکن
   - `GITHUB_REPO` — `MahdiHajiabadi675/ai-news-bot-telegram`
3. در Cloudflare → Worker → **Settings → Triggers → Cron Triggers** → `17 * * * *`

اگر این‌ها تنظیم نشوند، همان cron خود GitHub (`17 * * * *`) کار را انجام می‌دهد.

تمام! ✅ ربات هر ۱ ساعت اجرا می‌شود و Worker به‌صورت ۲۴/۷ فعال است.

## منابع اخبار

لیست کامل در `FEEDS` (`src/collectors.py`)؛ وضعیت زندهٔ هر فید با `/feeds`.

- **سایت رسمی شرکت‌ها:** OpenAI، Google AI، Google Research، DeepMind، HuggingFace، Microsoft Research، NVIDIA، AWS ML، Apple ML
- **Anthropic و Meta AI:** فید رسمی ندارند؛ از فیدهای جامعه (`Olshansk/rss-feeds`) استفاده می‌شود که هر ساعت از سایت رسمی ساخته می‌شوند
- **رسانه‌های AI:** MIT Tech Review، Ars Technica AI، TechCrunch AI، The Verge AI، Wired AI، VentureBeat AI، The Decoder، MarkTechPost
- **رسانه‌های عمومی (با فیلتر AI):** TechCrunch، The Verge، Ars Technica، دیجیاتو، زومگ، تک‌راسا

فیدها موازی خوانده می‌شوند و از هر فید «جدیدترین» آیتم‌ها (بر اساس تاریخ انتشار، نه ترتیب فید) بررسی می‌شود.

## اعتبار اولیهٔ منابع

اعداد بالا فقط نقطهٔ شروع‌اند؛ با تصمیم‌های شما تغییر می‌کنند (بخش «اعتبار پویای منابع»).
انتشار خودکار فقط وقتی انجام می‌شود که **اعتبار فعلی ≥ ۴** و خبر «قطعی» و امتیاز ≥ ۷۰ باشد
(`AUTO_TRUST_THRESHOLD` در `src/config.py`).
